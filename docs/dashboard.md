# The owner dashboard

The owner dashboard is the admin landing page (Default Admin, core's
administration theme, with Coffee and the Dashboard module, as in Drupal
CMS): offers waiting, recent sales and
profit, domains expiring, how each marketplace sync and registrar read is
doing, and the next steps of setting up.

## What it shows

- Offers waiting for an answer.
- Recent sales and their profit.
- The domains expiring soon.
- Each marketplace's sync: the last check and push, listings out of date or refused,
  the last failure, and pushes waiting in the queue.
- When each registrar account was last read.
- The next steps of setting up: add a registrar, import your domains, connect a
  marketplace, enable a payment gateway, point parked domains at this site
  (optional), and set the notification address.

Showing it asks no registrar or marketplace for anything, so it opens at once.

## Tasks

Beside it, the *Tasks* menu links what you do most: import domains, add a domain,
domains, answer offers, orders, domain handovers, registrars and marketplaces,
payment gateways, and pages. Each link shows only to those who may follow it.

The same pages, with *Expiring soon*, *Sales and profit*, *Expenses* and *Renewal
costs*, are under *Commerce > Domains*. For the routine, see
[Every day](every-day.md).
